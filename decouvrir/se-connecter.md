# Se connecter au serveur

## 🌐 Adresse et version

| Élément            | Valeur                  |
| ------------------ | ----------------------- |
| Adresse            | `play.clovergames.fr`   |
| Édition            | Minecraft **Java**      |
| Versions acceptées | **1.21 et supérieures** |

{% hint style="info" %}
**Minecraft Bedrock (console, mobile, Windows)** : la compatibilité est prévue mais n'est pas encore certifiée. Nous annoncerons l'adresse et le port Bedrock sur le [Discord](https://dsc.clovergames.fr) dès que les tests seront validés. N'utilisez pas d'adresse trouvée ailleurs entre-temps.
{% endhint %}

## ➕ Ajouter le serveur

1. Lancez Minecraft Java en version **1.21 ou supérieure**.
2. Ouvrez **Multijoueur**, puis **Ajouter un serveur**.
3. Nom du serveur : `Clover Games`.
4. Adresse du serveur : `play.clovergames.fr`.
5. Validez, puis rejoignez le serveur.

## 🧩 Mods et clients autorisés

Les clients et mods **strictement esthétiques ou de confort** sont autorisés. Tout ce qui procure un avantage de jeu est interdit. Voir le [Règlement](../le-serveur/reglement.md).

{% tabs %}
{% tab title="Autorisés" %}
* **Clients** : Badlion, Lunar Client, LabyMod.
* **OptiFine**.
* **ReplayMod**, uniquement pour l'enregistrement.
* **Schematica / Litematica**, sans les modes _printer_, _easyplace_ ni copier-coller.
* **Toggle Sneak** et **Toggle Sprint**.
* **Inventory Tweaks**.
* **Minimap**.
{% endtab %}

{% tab title="Interdits" %}
* Tout client ou module offrant un avantage : _killaura_, _reach_, _aimbot_, _fly_, _x-ray_, _auto-clicker_…
* Les macros automatisant le combat ou la récolte.
* Toute modification permettant de voir à travers les blocs ou de repérer les joueurs.

Le doute profite au serveur : si un mod vous semble limite, demandez avant de l'utiliser sur le [Discord](https://dsc.clovergames.fr).
{% endtab %}
{% endtabs %}

## 🧭 Premiers repères en jeu

| Commande   | Effet                     |
| ---------- | ------------------------- |
| `/help`    | Aide générale en jeu      |
| `/rules`   | Rappel du règlement       |
| `/spawn`   | Retour au point de départ |
| `/discord` | Lien vers le Discord      |
| `/site`    | Lien vers le site         |

La liste complète est sur [Toutes les commandes](../reference/commandes.md).

## 🛠️ En cas de problème de connexion

1. Vérifiez que votre version est bien **1.21+**.
2. Vérifiez l'adresse : `play.clovergames.fr`, sans port ni espace.
3. Consultez le canal d'annonces du [Discord](https://dsc.clovergames.fr) : une maintenance est peut-être en cours.
4. Si le problème persiste, ouvrez un ticket : [Support et signalements](../le-serveur/support-et-signalements.md).
