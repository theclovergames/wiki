# Support et signalements

Tout passe par le [Discord Clover Games](https://dsc.clovergames.fr). C'est le canal officiel de support : le staff n'assure pas d'assistance par message privé en jeu ni sur un autre réseau.

{% hint style="warning" %}
Un membre du staff ne vous demandera **jamais** votre mot de passe, un code de connexion, un moyen de paiement ni l'accès à votre compte. Toute demande de ce type est une tentative d'arnaque : signalez-la.
{% endhint %}

## Signaler un joueur

Ouvrez un ticket sur le [Discord](https://dsc.clovergames.fr) en indiquant :

| Information | Pourquoi |
| --- | --- |
| Le pseudo exact du joueur | Pour l'identifier sans ambiguïté |
| La date et l'heure approximatives | Pour retrouver les journaux |
| Le mode de jeu concerné | Pour cibler la vérification |
| Ce que vous avez constaté | Pour qualifier l'infraction |
| Une capture d'écran ou une vidéo | **Décisif** pour une accusation de triche |

{% hint style="info" %}
Sans preuve, un signalement de triche ne peut généralement pas aboutir. Une courte vidéo vaut mieux qu'une longue description. ReplayMod est autorisé pour l'enregistrement.
{% endhint %}

À ne pas faire :

- accuser publiquement un joueur dans le chat — cela peut être sanctionné ;
- relancer le ticket toutes les cinq minutes ;
- signaler un joueur parce qu'il est simplement meilleur que vous.

## Signaler un bug

Un bug signalé de bonne foi n'est jamais sanctionné. **En revanche, l'exploiter l'est** — voir le [Règlement](reglement.md#7-bugs-et-failles).

Décrivez :

1. **Ce que vous faisiez** au moment du bug.
2. **Ce qui s'est passé** et ce que vous attendiez à la place.
3. **Comment le reproduire**, si vous le savez.
4. Le mode de jeu, l'heure et votre version de Minecraft.
5. Une capture ou une vidéo si le bug est visuel.

{% hint style="danger" %}
Une faille de **sécurité** (accès à des données, contournement de permissions, plantage du serveur) ne doit jamais être publiée. Signalez-la en privé au staff via un ticket, sans la décrire dans un canal public.
{% endhint %}

## Problème d'achat ou de crédits

Pour une commande non livrée, un débit incorrect ou un solde de crédits erroné, ouvrez un ticket avec :

- votre pseudo Minecraft ;
- la date de l'achat et le montant ;
- la référence de commande reçue par e-mail ;
- une capture de la confirmation de paiement.

Chaque mouvement de crédits est enregistré dans un journal consultable par le staff : une erreur de livraison peut donc être retrouvée et corrigée.

## Perte d'objet

| Cause | Traitement |
| --- | --- |
| Mort, inattention, autre joueur | Aucun remboursement |
| Bug avéré du serveur | Examiné sur ticket, avec preuve |
| Erreur de livraison boutique | Corrigée après vérification du journal |

## Contester une sanction

1. Ouvrez un ticket sur le [Discord](https://dsc.clovergames.fr) — jamais dans un canal public.
2. Indiquez votre pseudo, la date de la sanction et le motif affiché.
3. Expliquez factuellement pourquoi vous l'estimez injustifiée.
4. Joignez tout élément utile.

Ce qui aide : des faits, une chronologie, des preuves.
Ce qui n'aide pas : insister, multiplier les tickets, mettre en cause publiquement un membre du staff.

{% hint style="info" %}
Une sanction est réexaminée par un membre du staff **différent** de celui qui l'a prononcée lorsque la contestation porte sur le fond. La décision de réexamen est définitive.
{% endhint %}

## Contacter le staff

| Besoin | Où |
| --- | --- |
| Question générale | Canaux d'aide du [Discord](https://dsc.clovergames.fr) |
| Signalement, achat, sanction | Ticket sur le Discord |
| Partenariat, création de contenu | Ticket sur le Discord, catégorie dédiée |

Les rôles et responsabilités de chaque grade du staff sont décrits sur [Rangs et grades](rangs-et-grades.md#grades-du-staff).
