# Votre profil public

Dans les zones sociales du réseau, un **clic droit sur un joueur** ouvre son profil public : sa bio, son grade, son niveau, son temps de jeu et les réseaux qu'il a choisi de partager.

{% hint style="info" %}
**Cette fonction arrive avec la prochaine mise à jour.** Elle est prête, mais pas encore active sur les serveurs. Son ouverture sera annoncée sur le [Discord](https://discord.gg/theclovergames).
{% endhint %}

## 👀 Consulter un profil

Approchez-vous d'un joueur et faites un **clic droit** sur lui. Quatre conditions doivent être réunies :

| Condition | Détail |
| --- | --- |
| **Main principale vide** | Un objet en main sert à autre chose |
| **À 6 blocs au maximum** | Et dans le même monde |
| **Dans une zone sociale** | Lobby et abords du spawn. Vous **et** lui |
| **Aucun des deux en jeu** | Voir ci-dessous |

Le profil ne s'ouvre pas si l'un de vous deux est engagé dans une partie : match, replay ou observation sur le Practice, partie de BedWars quel que soit votre rôle, combat en cours sur le PvPSoup ou le SkyPvP.

{% hint style="info" %}
C'est volontaire. Une fenêtre qui s'ouvre au milieu d'un duel parce que vous avez cliqué sur votre adversaire, c'est un combat perdu.
{% endhint %}

## 🪪 Ce que voit un visiteur

| Information | D'où elle vient |
| --- | --- |
| Votre tête et votre pseudo | Votre compte |
| Votre grade | Votre rang sur le réseau |
| Votre bio | Ce que vous écrivez |
| Votre première venue | La date de votre premier passage |
| Votre niveau réseau | Votre progression |
| Votre temps de jeu | Votre activité cumulée |
| Vos réseaux | Ceux que vous avez ajoutés, selon leur visibilité |

Deux boutons complètent la carte : **ajouter en ami** et **inviter dans votre groupe**.

{% hint style="success" %}
**Rien de privé n'y figure, jamais.** Pas d'adresse IP, pas d'e-mail, pas de nom réel, pas d'UUID, aucun identifiant de liaison Discord ou site, aucune sanction ni note du staff. Le profil ne montre que ce que vous avez choisi d'y mettre, plus des statistiques de jeu déjà publiques.
{% endhint %}

Un joueur sous **pseudo d'emprunt** garde son anonymat : son vrai profil ne s'ouvre pas.

## ✏️ Remplir le vôtre

Ouvrez votre menu **profil**, puis la carte **Mon profil public**.

### La bio

Une ligne libre, **80 caractères au maximum**, sans couleurs ni mise en forme. Clic gauche pour l'écrire ou la modifier, clic droit pour la supprimer.

La saisie se fait **dans le chat**, le menu se referme le temps que vous écriviez. Deux mots à connaître :

* **`annuler`** abandonne la saisie sans rien enregistrer ;
* **`confirmer`** valide une suppression.

Une saisie laissée en attente expire au bout de **60 secondes**.

{% hint style="warning" %}
La bio est soumise au [Règlement](reglement.md) comme n'importe quel message. Une bio insultante, publicitaire ou trompeuse est retirée par le staff, et son auteur sanctionné.
{% endhint %}

### Vos réseaux

Six plateformes sont acceptées. Vous entrez soit votre identifiant, soit l'adresse complète :

| Plateforme | Format attendu |
| --- | --- |
| **Discord** | Votre nom d'utilisateur public, jamais un lien |
| **YouTube** | `https://www.youtube.com/@identifiant` |
| **Twitch** | `https://www.twitch.tv/identifiant` |
| **TikTok** | `https://www.tiktok.com/@identifiant` |
| **Instagram** | `https://www.instagram.com/identifiant/` |
| **X** | `https://x.com/identifiant` |

{% hint style="warning" %}
**Les liens raccourcis et les autres domaines sont refusés.** Une adresse `bit.ly`, un lien vers un site personnel ou une URL avec des paramètres de suivi ne passeront pas. C'est ce qui empêche le profil de devenir un support de redirection ou d'arnaque.
{% endhint %}

Sur le profil, Discord propose **Copier**. Les autres proposent **Ouvrir** et **Copier**.

### Qui voit quoi

Chaque réseau porte sa propre visibilité. Un clic droit dessus la fait défiler :

| Visibilité | Qui le voit |
| --- | --- |
| **Public** | Tous les joueurs |
| **Amis** | Uniquement vos amis confirmés |
| **Masqué** | Vous seul |

Vous pouvez donc afficher votre chaîne YouTube à tout le monde et réserver votre Discord à vos amis.

{% hint style="info" %}
Le bouton **Aperçu public** montre votre profil tel qu'un joueur qui n'est pas votre ami le voit. C'est le moyen sûr de vérifier ce que vous exposez vraiment avant de le laisser en place.
{% endhint %}

## 🧹 Modération

Le staff peut consulter un profil, en retirer une bio ou un réseau, ou le réinitialiser entièrement. Chaque intervention est enregistrée.

Un profil qui sert à contourner le règlement, à faire de la publicité pour un autre serveur ou à diriger vers un contenu interdit relève du [Support](support-et-signalements.md) comme tout le reste.
