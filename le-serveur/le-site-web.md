# Le site web

Le site **[clovergames.fr](https://clovergames.fr)** prolonge le serveur : vos statistiques, les classements, la boutique et la gestion de votre compte s'y trouvent.

Créer un compte n'est **pas obligatoire** pour jouer. Il l'est pour la boutique et pour retrouver vos statistiques en dehors du jeu.

## 👤 Créer votre compte

Quatre façons de vous inscrire et de vous connecter :

- **Discord**
- **Microsoft**
- **Google**
- **Adresse e-mail** et mot de passe

Vous pouvez lier plusieurs de ces méthodes au même compte, puis en délier une depuis vos paramètres.

### Lier votre compte Minecraft

C'est l'étape qui donne son intérêt au site : une fois votre compte Minecraft associé, le site affiche votre **pseudo**, votre **UUID** et vos **statistiques de jeu**.

C'est aussi ce qui permet à la boutique de livrer vos achats sur le bon compte.

La liaison se fait par un **code à usage unique**, généré en jeu :

1. Connectez-vous sur `play.clovergames.fr` et tapez **`/lier`**.
2. Le jeu vous affiche un code de huit caractères, du type `ABCD-EFGH`, **valable 10 minutes**.
3. Sur le site, ouvrez votre profil, puis **Paramètres**, et saisissez ce code dans la carte **Compte Minecraft**.
4. Le jeu vous confirme la liaison.

{% hint style="success" %}
**Personne ne peut lier votre compte à sa place.** Seul quelqu'un connecté en jeu sur ce compte peut voir le code, ce qui prouve que vous en êtes bien le propriétaire. Aucun mot de passe n'est échangé.
{% endhint %}

Quelques précisions utiles :

* Retaper `/lier` pendant la validité **réaffiche le même code** au lieu d'en créer un autre.
* `/lier annuler` invalide le code en cours si vous vous êtes trompé de fenêtre.
* Les tirets et les espaces sont ignorés à la saisie.
* Si vous étiez hors ligne au moment de la validation, la confirmation vous parvient à votre prochaine connexion.

Le même code fonctionne pour lier votre **Discord** : voir [Le bot Discord](bot-discord.md#lier-votre-compte-minecraft).

## 🔒 Sécurité du compte

### Double authentification

Vous pouvez activer la **double authentification (2FA)** par application d'authentification (TOTP) : Google Authenticator, Authy, Aegis ou équivalent.

Des **codes de secours** vous sont fournis à l'activation. Conservez-les ailleurs que sur votre téléphone : ce sont eux qui vous permettront de récupérer votre compte si vous perdez l'accès à votre application.

{% hint style="success" %}
Si vous possédez des grades ou des achats, activez la 2FA. C'est la seule protection réelle contre le vol de compte, et elle prend deux minutes.
{% endhint %}

### Mot de passe

Modifiable depuis vos paramètres. Si vous vous êtes inscrit via Discord, Google ou Microsoft, vous pouvez définir un mot de passe pour vous connecter aussi par e-mail.

{% hint style="danger" %}
Aucun membre du staff ne vous demandera **jamais** votre mot de passe, un code de double authentification ou un code de secours. Toute demande de ce type est une tentative d'arnaque. Voir [Support et signalements](support-et-signalements.md).
{% endhint %}

## ⚙️ Vos paramètres

| Réglage | Détail |
| --- | --- |
| **Pseudo du site** | Modifiable, avec un délai de **7 jours** entre deux changements |
| **Compte Minecraft** | Synchroniser, mettre à jour ou dissocier |
| **Adresse e-mail** | Modifiable |
| **Comptes liés** | Voir et délier Discord, Google, Microsoft |
| **Apparence** | Thème clair, sombre, ou selon votre système |
| **Communications** | Choisir de recevoir ou non les actualités et promotions |
| **Suppression du compte** | Définitive |

{% hint style="info" %}
Le délai de 7 jours sur le pseudo évite les changements d'identité à répétition, qui compliquent la modération et rendent les classements illisibles.
{% endhint %}

## 🛒 Boutique et commandes

La boutique est organisée par catégories. Vous ajoutez au panier, puis payez de façon sécurisée.

Votre **historique de commandes** est consultable à tout moment depuis votre profil : c'est là qu'il faut regarder en premier si un achat n'a pas été livré.

Vos **pièces sont synchronisées** entre le site et le jeu. Un achat effectué sur le site est répercuté en jeu automatiquement, sans avoir à vous reconnecter. Voir [Pièces](credits-economie.md).

En cas de problème de livraison ou de solde, ouvrez un ticket : voir [Support et signalements](support-et-signalements.md#probleme-dachat-ou-de-pieces).

{% endhint %}
